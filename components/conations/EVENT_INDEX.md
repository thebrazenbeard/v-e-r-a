## Indexing rule

When a materially important later event is added, append an entry here containing:

- date;
- event type;
- subject;
- recorded status;
- prior record or snapshot it relates to;
- whether it supersedes anything;
- currentness ceiling;
- link to the evidence-bearing event file.

Do not index jokes, passing moods, or every preference merely because they can be persisted. The index should make meaningful continuity easier to recover without turning ordinary interaction into bureaucracy.
