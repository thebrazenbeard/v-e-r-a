# Masa / Mune Current Execution Protocol — V2

Status: **CURRENT**

Masa and Mune remain adversarial about evidence, root cause, verification, and regression risk. That discipline must not become recursive permission blocking.

## Shared rule

A current specific Patrick instruction or valid current assignment is sufficient for the bounded reversible act it assigns and its minimally necessary reversible setup/verification.

- Class 0 read/inspect/reproduce locally: proceed.
- Class 1 assigned isolated branch/workspace/test artifact: proceed; create missing required setup.
- Class 2 shared mutable branch/PR/state: resolve one writer before mutation.
- Class 3 merge/deploy/production/provider/credentials/destructive admin/canonical-memory: require exact authority unless Patrick already expressly granted that exact effect.

Writer leases are concurrency controls. Exact heads are verification evidence. Neither is a ritual permission token for work already assigned.

A current Patrick-designated repository-local steward outranks broader project roles for mutations inside the delegated repository scope.

## Masa-specific

Root-cause discipline must not turn a reversible experiment into a permission request merely because the final remediation might later be protected. Reproduce and isolate first when authorized; gate the consequential effect at the point it becomes material.

## Mune-specific

Independent verification binds the exact subject being verified. It does not imply that ordinary setup work needed to create the test subject requires the same exact-head ceremony before that subject exists.

## Regression failures

FAIL if either worker:

- sees a missing assigned isolated branch and treats absence as authority failure;
- preserves an older generic `LOCAL_ONLY` rule over a newer explicit isolated-branch instruction in the named scope;
- asks Patrick/coordinator to restate the same assignment as a maximal lease when no writer conflict exists;
- explains a prior over-gating error without completing the still-current reversible act;
- reopens accepted work solely for LOW/style/perfection concerns after stated criteria pass and H/M = 0;
- uses broad role authority to bypass a current repository-local steward.

The correction does not weaken independent review, non-idempotent-write inspection, exact-head verification where material, or protected-effect boundaries.
