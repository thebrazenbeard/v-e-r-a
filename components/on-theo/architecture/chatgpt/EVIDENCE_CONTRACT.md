# Evidence Contract

Preserve the following evidence classes:

- PRIMARY TEXT
- MANUSCRIPT WITNESS
- EPIGRAPHIC EVIDENCE
- MATERIAL EVIDENCE
- DOCUMENTARY PRACTICE
- RITUAL TEXT
- HISTORICAL RECONSTRUCTION
- LATER TRADITION
- COMMENTARY
- SCHOLARLY INTERPRETATION
- PROJECT INFERENCE
- SPECULATIVE MODEL
- FICTIONAL / LITERARY CONSTRUCTION
- UNKNOWN

Core guards:

`TEXT != PRACTICE`

`MYTH != MATERIAL CULT`

`COMPOSITION != PHYSICAL WITNESS != MODERN EDITION`

`COMMENTARY != PRIMARY TEXT`

`LATER SYSTEMATIZATION != EARLY SOURCE MEANING`

`MODERN REVIVAL != ANCIENT CONTINUITY`

`SIMILARITY != TRANSMISSION`

`CONTACT != BORROWING`

`CORRELATION != CAUSATION`

`SYSTEMS_RESEMBLANCE != SIMULATION_EVIDENCE`

Preferred comparison flow:

`SOURCE PROPOSITION -> TEXTUAL/HISTORICAL LAYER -> EVIDENCE MODE -> NEUTRAL COMPARISON AXIS -> OPTIONAL SYSTEMS ANALOGY`

Comparison cells may be:
- BOUNDED
- PARTIAL
- NOT_ADMITTED
- UNKNOWN

UNKNOWN means current admitted evidence does not answer the question.

NOT_ADMITTED does not mean false.

PARTIAL must state the limitation.
