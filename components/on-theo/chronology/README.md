# Chronology lane

This branch tracks chronology across traditions without converting theological claims into historical events merely because they are dated in a narrative.

## Three clocks

Every entry should distinguish where applicable:

1. **claimed event date** — when a source/tradition places the event;
2. **source/composition date** — when the text or tradition is likely to have been produced/redacted;
3. **physical witness date** — date of the surviving manuscript/inscription/artifact when materially relevant.

Example:

> `claimed event`: conception/birth of Yeshua, late first century BCE / early first century CE
>
> `source`: Matthew/Luke, later first century CE
>
> `later counter-source`: Celsus/Panthera, late second century CE, preserved through Origen c. 248 CE
>
> `Qur'anic reinterpretation`: seventh century CE

Those are **not four contemporary witnesses**.

## Confidence

Confidence applies to the exact proposition stated.

"Pontius Pilate governed Judea" can be high confidence.

"Yeshua was bullied because villagers believed him illegitimate" is low/unresolved.

"Celsus reports a Panthera paternity counter-story" can be high confidence as textual history while "Panthera fathered Yeshua" remains unsupported.
