Before attempting any reconstruction of that missing field, this packet asks:

What does the same tablet do when the Ugaritic field *is* preserved for Baal?

The result is methodologically important.

## 2. This is not a clean three-way theological identity

Imzuanna is not a straightforward Mesopotamian weather-god equivalent to Teššub and Baal.

Modern discussion notes the oddity explicitly.

Nougayrol proposed that the equation exploits the first sign of Imzuanna's name:

IM

which is also used logographically for storm/weather gods.

Modern scholarship therefore treats the row as evidence that scribal equivalence can use:
- graphic association;
- learned wordplay;
- sign-based analogy;
- functional accommodation

rather than simple one-to-one theological identity.

## 3. Gender mismatch is itself a hostile control

The Mesopotamian Imzuanna is a goddess.

Teššub and Baal are male storm gods.

Yet the trilingual list aligns them.

Therefore the equation cannot safely be read as:

"these three deities are identical in all cultic and mythological respects."

The scribal practice tolerates a mismatch that a strict theological-identity model would find difficult.

Control:

GOD_LIST_EQUATION
!=
FULL_ONTOLOGICAL_IDENTITY.

## 4. Baal and Teššub alignment is still historically meaningful

The row does support a learned correspondence between:
- Hurrian Teššub;
- Ugaritic Baal.

That pairing is independently intelligible because both function as major storm/weather deities in northern Syrian religious environments.

But the presence of Imzuanna in the same row warns that the list's mapping logic is not limited to exact cultic identity.

Recommended type:

BAAL_TEŠŠUB =
SCHOLASTIC_FUNCTIONAL_EQUIVALENCE_HIGH.

Not automatically:

BAAL_TEŠŠUB =
TOTAL_THEOLOGICAL_IDENTITY.

## 6. Baal cannot be restored into the Dumuzi gap from this row

One might argue:

the tablet explicitly knows Baal as a local equivalent elsewhere;
Dumuzi is associated with death/return;
Baal is associated with death/return;
therefore Baal filled the lost Dumuzi field.

The same tablet actually weakens that inference.

Why?

Because the preserved Baal row already maps Baal through a distinct learned equation:

Imzuanna -> Teššub -> Baal.

Nothing in the surviving Dumuzi row links it to Baal.

Therefore:

KNOWN_BAAL_ROW
does not license:
DUMUZI_ROW_RESTORATION_AS_BAAL.

## 7. One local deity can participate in scholastic mapping without proving source dependence

A local deity's presence in a lexical equation shows that scribes knew how to place that deity inside a multilingual classification system.

It does not prove:
- that the local deity's myths were translated from the foreign deity's myths;
- that their cults merged;
- that the local deity derived historically from the foreign deity;
- that every property of one transfers to the other.

Thus:

LEXICAL_EQUIVALENCE
!=
NARRATIVE_DEPENDENCE.

This rule applies equally to:
- Baal/Teššub;
- Utu/Šimigi/Šapšu;
- any future recovered Dumuzi equation.

## 9. Implication for transmission methodology

The project now has direct evidence for at least three different situations on one tablet:

### Preserved functional-looking equation
Utu = Šimigi = Šapšu.

### Preserved irregular / sign-play-sensitive equation
Imzuanna = Teššub = Baal.

### Lost local equation
Dumuzi = du-mu-zi = [lost].

This provides an unusually strong internal methodological control.

The correct workflow is:

1. recover the actual row;
2. identify the scribal rationale if possible;
3. type the equation as scholastic;
4. separately test cultic and mythological identity;
5. separately test transmission.
