## 4. The same Ugarit tablet demonstrates what a preserved equivalence can look like

Other rows in Ugaritica 5, 137 preserve more of the multilingual mapping.

For example, the Utu row preserves a correspondence:

=

=
Ugaritic Shapshu.

This demonstrates that the tablet's local adaptation can explicitly align a Mesopotamian deity with Hurrian and Ugaritic names.

By contrast:
- Inana = Shaushka = [Ugaritic field lost];
- Dumuzi = du-mu-zi = [Ugaritic field lost].

The loss is therefore textually meaningful:
the local mapping once occupied a column, but its value is unavailable.

## 5. A god-list equivalence is a scribal correspondence

Even where a trilingual god list preserves an equivalence, the safest proposition is:

SCRIBE/LEXICAL_TRADITION_ALIGNS A WITH B.

That is not automatically identical to:

A AND B ARE THE SAME DEITY IN EVERY CULTIC, MYTHOLOGICAL, OR HISTORICAL SENSE.

God lists are learned classification tools.

Their equations can encode:
- functional analogy;
- interpretive translation;
- scribal convention;
- local accommodation;
- theological identification at a particular learned level.

The project should therefore type a recovered equation, if one is ever found, as:

SCHOLASTIC_EQUIVALENCE

before considering stronger:
CULTIC_IDENTITY
or
MYTHOLOGICAL_IDENTITY.

## 6. Baal cannot fill the missing field by motif similarity

The following argument is invalid:

Dumuzi has death/return associations.
Baal has death/return associations.
Therefore the lost Ugaritic equivalent beside Dumuzi must have been Baal.

That uses the target hypothesis to reconstruct the missing evidence.

Control:

MOTIF_SIMILARITY
!=
LOST_TEXT_RECONSTRUCTION.

There is currently no source-specific basis for restoring Baal in the broken Ugaritic column.

## 7. Shapshu parallel is not a license to infer Baal

The preserved Utu -> Shimigi -> Shapshu row shows that local Ugaritic divine names could occupy the third column.

It does not establish a deterministic rule by which modern researchers can infer a missing third-column deity from general function.

Different traditions can:
- merge roles;
- split roles;
- use one local deity for multiple foreign deities;
- preserve foreign names;
- leave no neat one-to-one correspondence.

Therefore the Dumuzi row must remain unresolved.
