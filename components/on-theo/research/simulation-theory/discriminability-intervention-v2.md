# Simulation Theory V2 — Discriminability and Intervention Tests

Status: RESEARCH_PACKET / REVIEW_REQUIRED

## Purpose

V1 separated simulation argument, external simulation, digital ontology, consciousness assumptions, empirical-test proposals, and theology analogies. V2 asks a harder question:

Under what conditions could an embedded observer rationally distinguish an externally implemented world from a non-simulated world with the same observable regularities?

## 1. Generic simulation hypotheses are too permissive

An unconstrained simulator can in principle emulate any observation compatible with the observer's evidence. That flexibility weakens empirical content rather than strengthening it.

If every possible result can be explained by 'the simulator chose it', then the model has little or no discriminating power.

Norman Swazo's critique explicitly targets the difficulty of giving the generic simulation hypothesis admissible falsification conditions. This does not refute every simulation model; it highlights that a scientific test requires architectural commitments.

## 2. Model-specific simulation hypotheses can be testable

Beane, Davoudi, and Savage are useful precisely because they do not test 'simulation' in the abstract. They analyze observable consequences of a particular numerical lattice architecture.

A null result can constrain that implementation family while leaving other architectures untouched.

Project rule: EMPIRICAL_TEST_RESULT must bind to a named simulator model class.

## 3. Observer counting is not neutral

Bostrom-style reasoning requires a reference class and assumptions about which implemented entities count as observers.

Crawford's freak-observer objection and related anthropic critiques show that population dominance alone does not automatically license self-location into the largest proposed population.

Kipping's Bayesian treatment likewise demonstrates that prior/model uncertainty materially changes the apparent probability.

Keith Harris further attacks one premise by arguing that posthuman civilizations may be unlikely to run large numbers of ancestor simulations.

Therefore observer-counting claims must expose at least:
- observer/reference class;
- simulator-production-rate assumption;
- consciousness criterion;
- prior/model uncertainty;
- duplicate/copy counting rule.

## 4. Consciousness is load-bearing

A behavioral simulation can be functionally indistinguishable from a conscious organism while the metaphysical question of phenomenal experience remains unresolved.

If substrate independence is false, Bostrom-style conscious-simulant population counts can collapse even if detailed behavioral simulations are technologically possible.

Conversely, if functional organization is sufficient for consciousness, the observer-population problem becomes stronger.

V2 does not resolve philosophy of mind; it marks the dependency.

## 5. Provenance underdetermination

Suppose two worlds are internally observationally identical:

- World A is fundamental at its own level.
- World B is implemented by an external computing system.

If every observable history available to inhabitants is identical, no purely internal observation can distinguish A from B.

This is a PROJECT_INFERENCE about underdetermination, not a proof that simulation is unknowable under every model.

Distinguish:
- provenance-underdetermined worlds;
- implementation-leaking worlds;
- intervention-capable worlds;
- worlds with externally injected but internally detectable information.

## 6. Interventions and miracles

An external operator could in principle alter internal state, instantiate matter, restore prior states, supply information, or create an in-world agent.

That makes many religious miracle claims simulation-compatible.

But compatibility is not evidence.

For a miracle report to favor external intervention over ordinary alternatives, it would need features that are comparatively expected under an intervention model and unexpectedly difficult under:
- error;
- legend;
- fraud;
- coincidence;
- unknown internal physics;
- ordinary but rare causation;
- psychological/religious experience.

Without a discriminator, 'simulator intervention' is an extra description, not an evidential gain.

## 7. Revelation as an information-channel hypothesis

Revelation can be formalized as a claim that information enters an embedded agent from a causal source not recoverable from ordinary in-world channels.

A strong intervention model would need prospective, high-specificity information that:
- was not available to the receiver by ordinary means;
- is recorded before verification;
- resists broad interpretive matching;
- repeatedly outperforms chance and alternative-information channels.

Ancient religious texts rarely provide experimental control of this kind. Therefore simulation theory currently does not raise their historical evidentiary weight.

## 8. Resurrection as state-restoration model

Simulation theory makes state restoration or re-instantiation conceptually straightforward for a privileged external operator. This removes one metaphysical objection: a simulated world's ordinary local causal laws need not be ultimate constraints on its implementer.

But it creates no historical evidence that a particular resurrection occurred.

A resurrection claim still requires historical analysis of event testimony, source chronology, alternative explanations, and the meaning of identity continuity under re-instantiation.

## 9. Yeshua interface

For the historical Jesus project, simulation theory currently changes conceptual possibility more than historical probability.

Miracles, revelation, incarnation, resurrection, and eschatological transformation all have simulation analogues. Yet the first-century evidence remains explainable within Jewish apocalyptic, prophetic, wisdom, healing, and resurrection traditions without invoking simulation.

Current project status:
SIMULATION_COMPATIBILITY = YES for many Christian claims.
SIMULATION_SPECIFIC_EVIDENCE = NONE_ESTABLISHED.

## 10. Strongest V2 inference

The most useful scientific/philosophical question is not 'Can a simulator do X?' but:

What observation would be more expected if X were an external implementation/intervention than if the world were fundamental or governed by unknown internal law?

That question converts simulation theory from a universal escape hatch into a constrained inference problem.

## World Zero experiment priority

Construct paired toy worlds with identical observer-accessible histories but different provenance, then test which provenance claims embedded agents can rationally justify.

Second experiment: introduce controlled implementation leakage into only one world and measure the evidence threshold at which external provenance becomes distinguishable.

No toy-world result may be promoted into evidence that our universe is simulated.
