# Shinto — Hostile Source-Control Lane V1

Status: HOSTILE_REVIEW / ANTI-BACKPROJECTION

This branch exists to challenge overconfident claims made from the main Shinto research lane.

## Primary hostile questions

1. Is a claimed "ancient Shinto doctrine" actually first visible in Kojiki, Nihon shoki, Engishiki, medieval theology, Kokugaku, Meiji policy, or modern scholarship?
2. Is a kami identity stable across sources?
3. Is a genealogy preserved consistently?
4. Is a myth being converted into literal political history?
5. Is later shrine practice being projected into an earlier period?
6. Is Buddhist-Shinto interaction being erased to manufacture a "pure Shinto" continuity?
7. Is State Shinto being projected backward?
8. Is a modern English category such as "god", "soul", "hell", "sin", or "creation" distorting the source concept?

## Core source controls

Kokugakuin Encyclopedia of Shinto:
https://d-museum.kokugakuin.ac.jp/eos/

Important internal controls:
- Ancient Shinto discussions explicitly state that pre-documentary reconstruction is limited.
- Nihon shoki's divine-age sections preserve alternative accounts.
- Kami names, functions, and genealogies vary between Kojiki and Nihon shoki.
- medieval Shinto cannot be reconstructed without Buddhist interaction.

## Automatic downgrade rules

PREHISTORIC_CLAIM_FROM_LATE_TEXT_ONLY
=> HISTORICAL_RECONSTRUCTION, not PRIMARY_TEXT fact about prehistory.

KOJIKI_ONLY_GENEALOGY
=> one textual tradition, not universal Japanese belief.

NIHON_SHOKI_VARIANT_ACCOUNT
=> preserve alternatives; do not harmonize by default.

MEDIEVAL_HONJI_SUIJAKU_OR_OTHER_SYNCRETISM
=> do not relabel as timeless ancient Shinto.

MEIJI_STATE_FORMULATION
=> modern institutional history unless independent older evidence exists.

## High-risk comparison targets

- primordial couple comparisons;
- flood/creation parallels;
- solar-deity comparisons;
- underworld/hell parallels;
- purification/baptism parallels;
- imperial divine-descent claims;
- sacred mirror/tree/mountain universal-symbol claims.

Motif similarity alone never establishes diffusion.

## Review standard

Every strong reconstruction should provide:
- earliest source;
- witness date;
- genre;
- variant sources;
- political/institutional setting;
- archaeology if relevant;
- later reinterpretations;
- confidence;
- falsifier.

## Current disposition

This branch is intentionally skeptical.

Its job is not to prove Shinto claims false; it is to prevent later textual or political constructions from silently masquerading as ancient source-level fact.
