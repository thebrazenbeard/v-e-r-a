# Judaism lane

This lane reconstructs the Jewish conceptual world in which Yeshua/Jesus emerged before later Christianity is treated as a separate religion.

## Working frame

First-century Judaism was diverse rather than monolithic. Shared commitments included Israel's God, Torah, covenant, Temple/festival life, and Jewish identity, while major disagreements concerned interpretation, purity, resurrection, priestly authority, apocalyptic expectation, political accommodation/resistance, and the shape of divine restoration.

This lane therefore treats disputes between Yeshua and other Jews as intra-Jewish disputes unless evidence requires otherwise. "Jesus versus Judaism" is not a default category.

## Boundary

Rabbinic sources compiled centuries later can preserve earlier material but are not treated as transparent first-century transcripts. Christian sources describing Jewish opponents are likewise interested sources, not neutral ethnography.
