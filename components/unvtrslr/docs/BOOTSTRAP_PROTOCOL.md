# Semantic Bootstrap Protocol

## Objective

The bootstrap protocol is the heart of UNVTRSLR.

Its job is not to translate an already-known language. Its job is to establish enough shared semantics that translation becomes possible.

The strongest target condition is:

- no shared vocabulary;
- no shared tokenization;
- no assumed discrete messages;
- no shared ontology;
- potentially asymmetric sensors;
- only a partially shared environment and an available interaction surface.

The protocol should degrade gracefully when more common ground exists.

## Bootstrap loop

The recurring loop is:

`observe -> detect structure -> hypothesize signalhood -> hypothesize meaning -> predict -> choose discriminating interaction -> observe response -> update -> negotiate -> test -> conserve uncertainty`

This makes semantic learning active and experimental.

## Phase 0 — Establish an observable interaction surface

Before semantics, identify what can be observed and changed.

The system should inventory:

- available sensory channels;
- temporal resolution;
- spatial overlap;
- controllable outputs/actions;
- latency;
- noise;
- persistence;
- repeated environmental regularities;
- apparent agents or responsive systems.

In an interstellar broadcast, Phase 0 is largely a physical-layer and framing problem. In an embodied probe, it includes local sensing and action.

## Phase 1 — Discover candidate signalhood

The system should not assume that every observable behavior is communicative.

Candidate evidence that a pattern functions as a signal includes:

- repetition under similar circumstances;
- dependence on audience presence or state;
- recipient response contingency;
- correction/repetition after failed response;
- turn-like alternation;
- compression or regularity exceeding surrounding behavior;
- coordination improvement when the pattern is available;
- intentional-looking modulation of a controllable channel;
- response to imitation;
- mutual adaptation over repeated encounters.

The system should keep a null hypothesis that the behavior is not communication.

### Signalhood tests

Possible tests include:

- repeat a candidate pattern and observe whether behavior changes;
- alter timing while preserving other features;
- alter form while preserving context;
- present the same form under a different context;
- withhold a previously recurrent response;
- imitate only one dimension of a multimodal behavior;
- vary apparent audience attention.

The purpose is not to manipulate aggressively but to identify contingent structure.

## Phase 2 — Establish interaction primitives

Before teaching nouns, establish meta-communicative functions if they emerge.

Useful early functions may include:

- attention / attend-here;
- repeat;
- same;
- different;
- acknowledge;
- reject;
- choose;
- stop;
- continue;
- query/uncertainty;
- correction.

These are **candidate bootstrap functions**, not asserted cognitive universals.

They matter because a system with repair and confirmation can learn much faster than one-way labeling.

## Phase 3 — Ground stable shared regularities

Use phenomena that are simultaneously or independently observable and experimentally manipulable.

Potential anchors include:

- repetition and countable recurrence;
- periodicity;
- relative duration;
- direction;
- distance;
- ordering;
- spatial coincidence;
- symmetry;
- object persistence where both sides segment objects;
- physical transformations;
- motion;
- collision;
- response to intervention;
- dimensionless ratios;
- reproducible physical phenomena.

For interstellar contexts, shared physics may provide stronger anchors than arbitrary human notation. Lincos similarly begins with mathematical structure, but UNVTRSLR should not assume mathematics is already semantically shared; it must teach or demonstrate the mapping.

## Phase 4 — Infer candidate referents and relations

For every recurring signal pattern, maintain multiple hypotheses.

Example:

Observed pattern `X` occurs when a red sphere is salient.

Candidate hypotheses:

- X = red;
- X = sphere;
- X = that-object;
- X = look;
- X = desirable;
- X = near-sender;
- X = topic marker;
- X = random coincidence.

The system should construct interventions where those hypotheses diverge.

### Discriminating interaction example

To distinguish RED from SPHERE:

1. retain shape, change color;
2. retain color, change shape;
3. change both;
4. present a novel red object;
5. present a novel sphere;
6. reverse which party produces the signal.

The mapping is strengthened only when outcomes favor one semantic invariant across these changes.

## Phase 5 — Establish reusable relations

Single referents are not enough.

The system should test whether communication can express relationships such as:

- same/different;
- near/far;
- inside/outside;
- before/after;
- increase/decrease;
- source/destination;
- possession/access;
- actor/action/patient distinctions;
- conditional dependence;
- alternative/choice;
- uncertainty.

No specific relationship is assumed universal. These are experimental families.

## Phase 6 — Test compositionality

Once several mappings exist, probe whether they can combine systematically.

A candidate compositional system should handle new combinations that were never jointly trained.

Example progression:

- red;
- sphere;
- behind;
- two;

then test a novel configuration corresponding to:

`two red spheres behind the novel object`.

Success alone is not enough; alternative shortcuts must be excluded.

## Phase 7 — Role reversal

Receiver becomes sender.

If a receiver can only react to a signal but cannot productively use the same convention to guide the original sender, the shared semantic claim should remain weak.

Role reversal tests whether the mapping has become a negotiable convention rather than a one-sided response policy.

## Phase 8 — Counterfactual and causal testing

Move beyond description.

Example target structure:

`if support is removed, object will fall`.

Test whether a counterpart can use the communicated structure in a novel physical arrangement.

This helps distinguish grounded world-model relationships from surface association.

Causal claims should always remain separate from temporal correlation unless interventions support them.

## Phase 9 — Non-equivalence discovery

Introduce cases where the two agents' concept spaces differ.

Examples:

- one agent has a single category where the other has two;
- one agent distinguishes a sensory dimension unavailable to the other;
- one agent represents object identity while the other primarily represents trajectories;
- a source convention encodes social or epistemic information the target system lacks.

The translator should be able to stabilize:

- partial mapping;
- explanatory paraphrase;
- learned new target concept;
- or `NO_FAITHFUL_EQUIVALENT`.

## Phase 10 — Build a translation bridge

Only after semantic mappings have survived tests should the system create durable bridge entries.

Each bridge entry should include:

- source pattern/channel;
- segmentation rule;
- context bounds;
- semantic hypothesis structure;
- probability/calibration;
- establishment evidence;
- counterexamples;
- role-reversal result;
- compositional tests;
- target realization options;
- conservation ledger;
- last validation time/interaction.

## Phase 11 — Meta-communication and recursive bootstrapping

A mature system should eventually communicate about the communication system itself:

- this signal is uncertain;
- repeat more slowly;
- I interpret X as Y;
- I do not understand;
- these two forms appear equivalent;
- this distinction is missing in my representation;
- I am asking rather than asserting;
- I inferred this rather than observed it.

This is the point at which the bridge becomes substantially self-improving.

## Curriculum ordering

Do not assume one fixed curriculum is universal.

Candidate bootstrap order should be chosen adaptively using criteria such as:

- high observability;
- low ambiguity;
- controllability;
- repeatability;
- high mutual information;
- ability to generate discriminating tests;
- usefulness for later concepts;
- low dependence on human-specific embodiment.

A physics-heavy interstellar curriculum may differ sharply from a human-human language-control curriculum.

## Active experiment selection

When multiple meanings remain plausible, choose the next interaction to maximize expected discrimination while respecting safety constraints.

Conceptually:

`next_test = argmax(expected information gain over semantic hypotheses)`

This does not require a specific Bayesian implementation, but information-gain-style policies are natural baselines.

The system should also account for:

- cost;
- risk;
- counterpart burden;
- reversibility;
- communication latency;
- possibility of misinterpreting an intervention as hostile or meaningful.

## Repair protocol

A robust bootstrap requires repair behavior.

Candidate repair actions:

- repeat;
- simplify;
- isolate one variable;
- demonstrate contrast;
- request imitation;
- ask for choice between alternatives;
- revert to earlier established conventions;
- explicitly mark uncertainty;
- abandon a failed mapping.

## Stopping conditions

A semantic mapping should not be considered established solely because probability crosses an arbitrary threshold.

A stronger gate is a bundle of evidence:

- repeated predictive success;
- novel-instance success;
- context variation;
- intervention discrimination;
- role reversal;
- compositional reuse;
- no known simpler shortcut explaining performance;
- calibration on withheld trials.

Different semantic classes may require different subsets.

## Bootstrap failure is a valid result

The system must be able to conclude:

- no detectable communicative channel;
- insufficient shared environment;
- signals detected but semantics unresolved;
- conventions unstable;
- concepts partially overlap only;
- interaction budget insufficient;
- partner appears noncooperative or deceptive;
- physical channel too noisy;
- current ontology cannot express the discovered distinction.

A universal translator that cannot admit failure is not universal; it is a hallucination engine.
