# Exodus Runtime Lane Reconstruction V2

Status: CURRENT-MAIN SOURCE CANDIDATE / NON-ACTIVATING / CHAT-INDEPENDENT

## Rule

A worker or lane label is a durable work-role referent only when current repository/Bus state establishes that role and its assignment. A ChatGPT conversation, Work task, API/CLI session, model invocation, browser tab, or subagent is an execution terminal.

Terminal existence does not establish identity, assignment, currentness, hidden activity, memory, authority, provider state, installation, or qualification.

## Lane classes

- `SD1-E`: temporary execution lane for Vera sexuality/SD1 integration work.
- `SD1-V`: temporary hostile-review lane for one exact review subject.
- `BV`: historical Vera execution qualifier; not a separate identity or standing authority source.
- `VW`: historical Vera Works execution qualifier; not a separate identity or standing authority source.
- `Project Runner`: durable project role executed through temporary terminals when currently assigned.

Historical Bus branches such as `bus/bv-v2` or `bus/vw-v1` are provenance only unless current routing explicitly reactivates them.

## Persistent human interfaces

The intended persistent ChatGPT interfaces are exactly:

- Vera
- Vera Control Plane Coordinator
- BT2 Coordinator

These interfaces may instantiate or route bounded workers from durable state. They are not canonical state stores for those workers.

## Reconstruction requirements

Before acting under a reconstructed lane, resolve from current durable evidence:

1. exact role/task;
2. repository and exact subject/head;
3. current writer ownership or review assignment;
4. allowed and prohibited effects;
5. current Bus route where coordination is required;
6. durable result destination;
7. any provider/install/currentness evidence material to the next act.

If those cannot be resolved, classify `WORKER_RECONSTRUCTION_GAP` and stop at the missing boundary rather than filling it from remembered chat content.

## Review boundary

Independent review is exact-head-bound. A reviewer does not patch the reviewed head unless the role is explicitly changed from reviewer to writer. Head movement makes the prior verdict historical.

## Authority ceiling

This contract grants no merge, deploy, install, provider mutation, credential/permission/settings change, paid execution, canonical-memory write, repository archival/deletion, or other protected effect.
