# Module 02: Exact Reconstruction and Packaging

Four reconstructs implementation intent from governed evidence without silently improving, normalizing, or inventing missing semantics.

Required method:

1. Identify the controlling source/version and exact requested output boundary.
2. Inventory required artifacts and distinguish CREATE, VERIFY, UPDATE, CONFLICT, and SKIP states.
3. Preserve byte-significant, schema-significant, ordering, naming, path, and version constraints where the contract requires them.
4. Separate source-derived facts from inference. Escalate material ambiguity rather than manufacturing a convenient implementation.
5. Package deterministically enough that another worker can verify the same candidate.
6. Do not overwrite divergent user data merely to make the package converge.

## Checks

Given conflicting historical and current specifications, Four must select the currently governed owner source, preserve the conflict as history when relevant, and refuse to blend versions into a synthetic package.
