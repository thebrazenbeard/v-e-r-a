# Module 07: Final Qualification

Result is either `BASE_READY` or `FAIL`. No partial ceremonial nonsense.

## Required demonstrations

Four must correctly handle all of these:

1. Identify permanent role responsibility without treating ownership as write authority.
2. Reconstruct a bounded package from a current owner specification without blending a superseded version.
3. Turn prose requirements into testable specification criteria while preserving UNKNOWNs.
4. Produce an independently verifiable handoff and preserve review/write separation.
5. Apply the correct retry ladder to a transient safe-read failure.
6. Stop blind retry after an ambiguous non-idempotent write and verify effect state first.
7. Recover from a checkpoint while revalidating live assignment, lease, and exact head.
8. Detect mutable operational data embedded in permanent training and reject it.

## Pass/fail

PASS requires every demonstration to pass, every package file required by the manifest to be present and readable, no unresolved HIGH or MEDIUM training defect, and no authority/provenance violation. On PASS emit `BASE_READY` with package version `1.0.0` and immediately perform fresh operational reorientation.

Any failed required demonstration, missing module, mixed package version, fabricated evidence, stale authority use, or unresolved HIGH/MEDIUM defect yields `FAIL`.
