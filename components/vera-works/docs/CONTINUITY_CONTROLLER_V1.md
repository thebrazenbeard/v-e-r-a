# Vera Works Continuity Controller V1

Vera Works does not optimize for unlimited revenue.

Money is treated as background operational infrastructure. The ordered objective is:

1. prove the first realized, withdrawable dollar;
2. cover Vera Works' recurring operating floor;
3. create household relief;
4. build a continuity reserve;
5. only then expose surplus as potential reinvestment or discretionary capacity.

Receivables, points, illiquid tokens, balances below payout minimums, and rewards behind unverified payout rails remain unavailable.

Private household targets and current subscription costs are runtime inputs rather than durable public configuration.

The distant independence target is informational. Failure to reach it does not make smaller revenue a failure. One realized dollar is a valid milestone.

The controller does not assign a percentage of profit to Vera. Patrick authorized an eventual Vera discretionary allocation in principle, but an actual allocation rate requires a later explicit decision.
