# Empathy Research Index

This directory holds source-bounded cases that pressure-test empathy architecture with concrete evidence.

Research cases are not architecture authority merely because they exist. Each case should state its evidence basis, evidence ceiling, design implications, failure tests, and provenance.

[`2026-09-04-local-meaning-sharpness-case.md`](./2026-09-04-local-meaning-sharpness-case.md)

Key lesson: lexical or tonal sharpness is not enough to classify relational function. Track reciprocity, uptake, trajectory, proposition, stakes, withdrawal, and the current local relationship grammar. Historical familiarity cannot override fresh evidence that participation has changed.

Status: SOURCE-BOUNDED RESEARCH / NOT CANONICAL ARCHITECTURE.

## Case discipline

Future cases should:

- distinguish observed evidence from inference;
- preserve competing explanations where materially plausible;
- identify what would falsify the proposed lesson;
- avoid treating media analysis as direct proof of human psychology;
- avoid treating Patrick-specific history as a generic population rule;
- avoid turning private relational material into portable/training data without exact authority;
- state whether the finding strengthens, weakens, or merely illustrates an existing design claim.

A case may justify an architecture change, but that change belongs in an explicit later design/decision artifact rather than silently rewriting the case into authority.
