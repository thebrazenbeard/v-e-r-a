# Digital Ontology and Pancomputationalism V1

Status: `SOURCE-BASED TAXONOMY / REVIEW REQUIRED`

## Purpose

This packet prevents a recurring category error:

> `Reality is computational` does not by itself mean `Reality is a computer simulation run by an external agent`.

The distinction matters because many arguments presented as evidence for simulation actually support, at most, some form of computational description or digital ontology.

Primary reference:
- Stanford Encyclopedia of Philosophy, `Computation in Physical Systems`
- https://plato.stanford.edu/entries/computation-physicalsystems/

## 1. Computation as description

At the weakest level, physical systems can be **described** using computational formalisms.

This is ordinary scientific modeling and carries no ontological implication that the modeled system literally is a computer.

A planetary orbit may be numerically simulated without the planet being software.

Project classification:
- `MODELING_RELATION`
- no external simulation implication.

## 2. Physical computation

Some physical systems are designed or interpreted as computing systems.

Examples include digital computers, analog computers, quantum computers, biological information-processing systems, and engineered control systems.

The philosophical problem is to explain what makes a physical system implement one computation rather than another.

This matters for simulation theory because an overly permissive theory of implementation can trivialize the statement `the universe computes`.

If every sufficiently complex physical trajectory can be mapped onto arbitrarily many computations, computational description alone supplies little evidence about underlying ontology.

## 3. Weak pancomputationalism

Weak forms of pancomputationalism maintain that every physical system performs at least some computation or information processing.

Possible motivations include:

- every physical system has causal structure;
- every physical state carries information in some sense;
- computation tracks physical state transitions.

Even if true, this does not imply an external simulator.

Project relation:

`WEAK_PANCOMPUTATIONALISM` -> `EXTERNAL_SIMULATION`: `NO_ENTAILMENT`.

## 4. Unlimited / interpretivist pancomputationalism

Strong implementation arguments associated with Putnam/Searle-style critiques suggest that sufficiently unconstrained mappings may allow many physical systems to be interpreted as implementing many computations.

For simulation theory this creates a warning:

If `implements computation X` depends primarily on a chosen mapping rather than objective causal organization, then identifying computational structure in physics may not reveal deep metaphysical substrate.

Project guard:

A computational description counts as ontologically interesting only when the implementation relation is non-trivial and physically constrained.

## 5. Ontic pancomputationalism

Ontic pancomputationalism makes a stronger claim:

> Computation or computational/informational structure is fundamental to the physical universe.

Possible variants include:

- classical cellular-automaton ontology;
- quantum-computational ontology;
- information-first ontology;
- computational structuralism.

This is a metaphysical thesis about what our universe is.

It still does not require a programmer or parent universe.

## 6. Cellular-automaton universe

A classical digital-physics model may propose that fundamental reality consists of discrete cells/states updated according to local rules.

Names historically associated with digital-physics/cellular-automaton approaches include Konrad Zuse, Edward Fredkin, and later Stephen Wolfram, though their models differ.

A cellular-automaton universe could be interpreted in at least two ways:

1. **fundamental ontology** — the automaton simply is reality;
2. **implemented simulation** — the automaton is software running on another substrate.

The same formal state-transition rule does not decide between these metaphysical interpretations.

## 7. Quantum computational descriptions

Quantum information theory permits descriptions of physical evolution using qubits/qudits, quantum circuits, entanglement, and information-processing concepts.

Seth Lloyd and others have described the universe as a quantum computer in various senses.

V1 guard:

A quantum-computational reformulation of quantum mechanics may add conceptual power without changing empirical content.

Therefore:

`physics can be represented as quantum computation` != `our universe is simulated by an external quantum computer`.

## 8. Information ontology / `it from bit`

Wheeler's `it from bit` language and related information-first proposals motivate the idea that informational distinctions are fundamental.

But `information` is itself multiply defined:

- Shannon information;
- thermodynamic entropy;
- algorithmic information;
- semantic information;
- quantum information;
- physical distinguishability.

Arguments become invalid when they switch between these senses without notice.

Project requirement:

Every information-based simulation claim must specify which information concept is being used.

## 9. Mathematical / structural ontology

A further possibility is that reality is fundamentally mathematical or structural.

Such a view can resemble software metaphors because both emphasize formal relations over familiar material substance.

But mathematical structuralism does not automatically posit:

- temporal execution;
- a processor;
- memory;
- an external universe;
- an intentional programmer.

A mathematical object need not be `running` anywhere.

## 10. External simulation

The external simulation hypothesis adds propositions not contained in digital ontology:

1. there exists an implementation substrate outside the simulated world;
2. the simulated world's dynamics depend on that substrate;
3. a computational process on the substrate realizes the simulated world;
4. possibly, agents intentionally initiated or control the process.

An external simulation may be digital, analog, quantum, or something outside our current computation taxonomy.

Therefore the external-simulation hypothesis and digital ontology overlap but neither is identical to the other.

## 11. Computational structuralism and simulation realism

Chalmers-style structural/simulation realism can maintain that simulated objects are real because their causal/spatial relations are implemented by underlying computational structure.

This creates another distinction:

- `what makes virtual objects real?` is a metaphysical question about implemented structure;
- `is our world externally simulated?` is a provenance question.

One can accept structural realism about virtual worlds while assigning low probability to the claim that our own world is simulated.

| --- | --- | --- | --- | --- |
| Computational modeling | Physics can be modeled computationally | No | No | No |
| Weak pancomputationalism | Physical systems perform some computation | No | No | Usually not by itself |
| Ontic pancomputationalism | Computation is fundamental physical ontology | No | No | Depends on formulation |
| Cellular-automaton ontology | Fundamental states/rules are discrete automaton-like | No | No | Potentially |
| Quantum-computational ontology | Fundamental dynamics are quantum-computational | No | No | May be reformulation |

## 13. Common invalid inferences

### `Quantum mechanics is weird, therefore simulation`

Invalid without an intermediate model showing why the observed quantum structure is more likely under simulation than under non-simulated quantum physics.

### `The Planck length is a pixel size`

Unsupported. The Planck scale is constructed from physical constants and marks a regime where quantum gravity is expected to matter; it is not established as a literal lattice spacing.

### `Information is physical, therefore reality is software`

Invalid equivocation between physical information constraints and software ontology.

### `The universe obeys mathematical laws, therefore it is programmed`

Lawful/mathematical description does not entail intentional code authorship.

### `Discrete states imply digital computation`

Discrete spectra can occur in non-computational physical theories.

### `A simulation can reproduce physics, therefore physics is a simulation`

Representational adequacy does not establish ontological identity.

## 14. V1 project position

The most defensible current separation is:

`computational description`
→ possibly `physical computation`
→ possibly `ontic computational structure`
→ **additional unsupported step** → `external implementation`
→ **additional unsupported step** → `intentional simulator`.

Each arrow requires its own argument.

Accordingly:

- digital ontology: `METAPHYSICAL_MODEL / OPEN`;
- pancomputationalism: `METAPHYSICAL_AND_IMPLEMENTATION_DEBATE / CONTESTED`;
- external simulation: `SPECULATIVE_MODEL / UNRESOLVED`;
- inference from computational description to external simulator: `NOT ESTABLISHED`.
