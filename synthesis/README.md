# Commonality / synthesis lane

This branch explores overlap **without forcing agreement**.

It compares Jewish, Christian, Islamic, noncanonical, and speculative systems-language structures while preserving the distinction between:

- shared inherited tradition;
- later reinterpretation;
- explicit disagreement;
- structural similarity;
- modern project analogy.

## Inputs

Research inputs currently live on independent branches:

- `tradition/judaism`
- `tradition/christianity`
- `tradition/islam`

This branch does not merge those branches or declare one canonical. It creates derived comparative artifacts with explicit provenance.

## Modules

- `commonality-matrix.md` — side-by-side conceptual comparison.
- `GOD-model.md` — the speculative simulated-reality/controller hypothesis developed in conversation.
- `transmission-vs-convergence.md` — how to distinguish inheritance from coincidental/structural rhyme.
- `yeshua-substrate-skepticism.md` — narrow form of the "ancient insight, period vocabulary" hypothesis.
- `epistemic-tests.md` — what the GOD model can explain, what it cannot establish, and possible falsifiers/discriminators.

## Anti-harmonization rule

If Judaism, Christianity and Islam disagree, write the disagreement down.

A common pattern such as `creator -> world -> human accountability -> death -> postmortem divine action` does not mean the traditions agree on incarnation, atonement, crucifixion, Trinity, Torah, prophecy, revelation, or salvation.

The interesting object is often the **shape of the disagreement itself**.
